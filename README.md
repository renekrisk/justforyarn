# Crochet Website

A beautiful, handcrafted crochet product website built with React, TypeScript, and Vite.

## Features

- Immersive welcome screen with split yarn/artist design
- Product showcase with hover effects
- About the artist page
- Contact form for custom orders
- Responsive design with custom cursor
- Clean, modern editorial style

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router DOM
- Custom CSS design system

## Project Structure

```
src/
  components/
    CustomCursor.tsx
    Footer.tsx
    Header.tsx
    Icon.tsx
    WelcomeScreen.tsx
  pages/
    Home.tsx
    About.tsx
    Contact.tsx
  lib/
  assets/
```

## Customization

- Replace placeholder images in `public/` and `src/assets/`
- Update contact information in `src/components/Header.tsx` and `src/pages/Contact.tsx`
- Modify product listings in `src/pages/Home.tsx`
- Update brand colors in `src/index.css`
